### 컴포넌트 명세

| 컴포넌트 | 타입 | 상태 | 동작 |
|----------|------|------|------|
| 로고 | Static | — | 브랜드 이미지 |
| 이메일 Input | TextInput | empty/filled/error | 포커스 시 라벨 상단 이동 |
| 비밀번호 Input | PasswordInput | empty/filled/error | 비밀번호 표시 토글 |
| 로그인 Button | PrimaryButton | default/loading/disabled | 클릭→API→성공 시 D2로 이동 |
| Google 로그인 | OAuthButton | default/loading | OAuth 2.0 PKCE 흐름 |
| 프로모 코드 섹션 | Collapsible | collapsed/expanded | 클릭 시 입력 필드 표시 |
| 프로모 Input | TextInput + Button | empty/validating/success/error | 적용 → API 검증 → 결과 표시 |

### 에러 상태
- 로그인 실패: Input 하단에 빨간 텍스트 "이메일 또는 비밀번호가 올바르지 않습니다"
- 프로모 코드 만료: "이 프로모 코드는 만료되었습니다 (JC-3-I-0001)"
- 프로모 코드 사용 초과: "이미 사용된 프로모 코드입니다"
- 네트워크 오류: 상단 배너 "서버에 연결할 수 없습니다"
