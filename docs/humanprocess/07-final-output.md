```
## 요청사항
다음 5개 문서를 생성해주세요:

### 1. 면접 요약 (1페이지)
- 지원자 핵심 정보
- 강점/약점 요약
- 집중 확인 사항
- 질문 목록 요약

### 2. 지원자 프로필 (상세)
- 경력 상세
- 기술 스택 매칭 분석
- 코드 품질 평가
- 주목할 만한 경험/코드

### 3. 면접 스크립트
- 시작/마무리 멘트
- 질문별 상세 가이드
- 점수 기준
- 꼬리질문/힌트

### 4. 기술 용어집
- JD 관련 기술 설명
- 비개발자용 쉬운 설명
- 면접 중 참고 사항

### 5. 평가표 (인쇄용)
- 체크리스트 형식
- 점수 기입란
- 메모 공간
- 최종 평가란

각 문서는 마크다운 형식으로 출력해주세요.
```

## 문서 1: 면접 요약 (00_면접_요약.md)

```markdown
# 면접 요약

## 기본 정보
| 항목 | 내용 |
|------|------|
| 지원자 | [이름] |
| 포지션 | [백엔드 개발자] |
| 경력 | [5년차 / 미들] |
| 면접 일시 | [YYYY-MM-DD HH:MM] |
| 면접 유형 | 기술 면접 (60분) |

---

## 지원자 핵심 요약

### 한 줄 요약
> 5년차 Python 백엔드 개발자, 결제 시스템과 대용량 트래픽 처리 경험 보유

### 핵심 역량
1. ✅ Python/FastAPI 실무 경험 풍부
2. ✅ Redis 캐싱, 성능 최적화 경험
3. ⚠️ Kubernetes 경험 부족 (JD 우대사항)

### 스킬 매칭
- **필수 기술**: 4/4 보유 (100%)
- **우대 기술**: 2/4 보유 (50%)

---

## 면접 집중 사항

### 반드시 확인할 것 🎯
1. **대용량 트래픽 경험** - MAU 100만 주장의 구체적 검증
2. **캐시 전략 이해도** - 코드에서 발견된 Redis 구현 깊이 파악
3. **설계 능력** - 미들 레벨에 맞는 아키텍처 이해도

### 주의 관찰 사항 ⚠️
- 결제 처리 속도 40% 개선 → 구체적 방법/측정 확인
- 팀 리더 경험 → 실제 역할 범위 확인
```
