# 05. 면접 질문 생성

> 수집된 모든 분석 결과를 종합하여 맞춤형 면접 질문 생성

---

## 목표

이력서, 코드, JD 분석 결과를 바탕으로 10개의 맞춤형 면접 질문을 생성합니다.

---

## 질문 구성 전략

### 경험 레벨별 질문 비율

| 레벨 | Easy | Medium | Hard | 집중 영역 |
|------|------|--------|------|-----------|
| 신입 | 50% | 40% | 10% | 기본 개념, 학습 의지 |
| 주니어 | 30% | 50% | 20% | 실무 적용, 코드 품질 |
| 미들 | 10% | 50% | 40% | 설계 능력, 기술 선택 이유 |
| 시니어 | 0% | 30% | 70% | 아키텍처, 리더십, 트레이드오프 |

### 질문 카테고리

| 카테고리 | 설명 | 권장 비율 |
|----------|------|-----------|
| 코드 기반 | GitHub 코드 직접 인용 | 30% |
| 기술 개념 | 이론적 이해도 | 20% |
| 경험 기반 | 이력서/포트폴리오 경험 | 25% |
| 문제 해결 | 가상 시나리오 | 15% |
| 아키텍처 | 설계 능력 | 10% |

## 프롬프트 1: 코드 기반 질문 생성

### AI 프롬프트

```
다음은 지원자의 GitHub 코드 분석 결과입니다. 이 코드를 기반으로 면접 질문을 생성해주세요.

## 코드 분석 결과
[03-code-analysis에서 얻은 결과 붙여넣기]

### 주목할 만한 코드
[notable_implementations 내용]

## 지원자 정보
- 경력: [N년차]
- 경험 레벨: [신입/주니어/미들/시니어]
- 지원 포지션: [포지션명]

## 질문 생성 요청
코드 기반 질문 3개를 생성해주세요.

각 질문은 다음 형식으로:
{
  "questions": [
    {
      "id": "code-1",
      "category": "code_implementation",
      "difficulty": "easy/medium/hard",
      "question": "질문 텍스트 (구어체, 면접관이 읽을 수 있도록)",
      "source": {
        "file": "파일 경로",
        "line": "라인 번호",
        "code_snippet": "```언어\n관련 코드\n```"
      },
      "intent": "이 질문으로 확인하려는 것",
      "time_limit_minutes": 3-5,
      "follow_up": "꼬리 질문 1개"
    }
  ]
}

주의사항:
- 단순 암기 확인이 아닌, 이해도와 의사결정 과정을 물어야 합니다
- 코드를 작성한 이유, 대안, 트레이드오프를 물어보세요
- 질문은 구어체로, 면접관이 바로 읽을 수 있어야 합니다
```

### 예상 출력 예시

```json
{
  "questions": [
    {
      "id": "code-1",
      "category": "code_implementation",
      "difficulty": "medium",
      "question": "cache.py 파일에서 Redis 캐싱을 구현하셨는데요, TTL을 300초로 설정하신 이유가 있으신가요? 다른 값은 고려해보셨나요?",
      "source": {
        "file": "app/services/cache.py",
        "line": "52-58",
        "code_snippet": "```python\nasync def get_with_cache(key: str, ttl: int = 300):\n    cached = await redis.get(key)\n    if cached:\n        return json.loads(cached)\n    ...\n```"
      },
      "intent": "캐시 전략에 대한 이해도, 비즈니스 요구사항 고려 능력",
      "time_limit_minutes": 4,
      "follow_up": "캐시 무효화는 어떻게 처리하셨나요?"
    }
  ]
}
```

### AI 프롬프트

```
다음은 지원자의 이력서/포트폴리오 분석 결과입니다. 경험 기반 질문을 생성해주세요.

## 지원자 프로필
[02-document-analysis에서 얻은 결과 붙여넣기]

### 주요 경력
[work_experience 내용]

### 주목할 점
[notable_points 내용]

## 질문 생성 요청
경험 기반 질문 3개를 생성해주세요.

각 질문은 다음 형식으로:
{
  "questions": [
    {
      "id": "exp-1",
      "category": "experience_based",
      "difficulty": "easy/medium/hard",
      "question": "질문 텍스트",
      "reference": "이력서/포트폴리오의 어떤 내용을 기반으로 한 질문인지",
      "intent": "이 질문으로 확인하려는 것",
      "time_limit_minutes": 3-5,
      "probing_questions": [
        "답변에 따른 추가 질문 2-3개"
      ]
    }
  ]
}

주의사항:
- STAR 기법으로 답변할 수 있는 질문 (상황-과제-행동-결과)
- 구체적인 수치나 결과를 확인할 수 있는 질문
- 성공 경험뿐 아니라 실패/어려움 경험도 포함
```

## 프롬프트 5: 질문 통합 및 밸런싱

### AI 프롬프트

```
지금까지 생성한 모든 질문을 검토하고 최적의 10개를 선별해주세요.

## 생성된 질문 목록
[이전 프롬프트들의 결과 모두 붙여넣기]

## 지원자 정보
- 경력: [N년차]
- 경험 레벨: [레벨]

## 선별 기준
1. 난이도 분포 확인 (레벨에 맞게)
2. 카테고리 다양성 확보
3. 중복 주제 제거
4. 면접 시간 내 소화 가능 여부 (총 50-60분 가정)

## 요청사항
최종 10개 질문을 선별하고, 면접 순서를 정해주세요.

출력 형식:
{
  "final_questions": [
    {
      "order": 1,
      "id": "질문 ID",
      "category": "카테고리",
      "difficulty": "난이도",
      "question": "질문 텍스트",
      "time_limit_minutes": N,
      "intent": "확인하려는 것",
      "source": "코드/이력서/JD 중 근거",
      "notes_for_interviewer": "면접관 참고사항"
    }
  ],
  "interview_flow": {
    "opening": "면접 시작 멘트",
    "total_time_minutes": N,
    "difficulty_progression": "쉬움→어려움 순서인지 등"
  },
  "balance_check": {
    "difficulty_distribution": {"easy": N, "medium": N, "hard": N},
    "category_distribution": {"code": N, "experience": N, ...},
    "coverage": ["커버된 기술/역량 목록"]
  }
}
```

### Q1. [Easy] 자기소개 및 아이스브레이킹

### Q2. [Medium] 코드 기반 - 캐싱 전략
> "GitHub에서 Redis 캐싱을 구현하신 걸 봤는데요, TTL을 300초로 설정하신 이유가 있으신가요?"

- **시간**: 5분
- **근거**: `app/services/cache.py:52`
- **의도**: 캐시 전략 이해도, 의사결정 과정
- **코드**:
```python
async def get_with_cache(key: str, ttl: int = 300):
    cached = await redis.get(key)
    ...
```
- **꼬리질문**: "캐시 무효화는 어떻게 처리하셨나요?"

---

- **시간**: 5분

### Q10. [Hard] 아키텍처 - 시스템 설계
> "만약 현재 시스템의 트래픽이 10배로 증가한다면, 어떤 부분을 먼저 개선하시겠어요?"

## 팁

- **질문이 너무 어려운 경우**: 레벨을 낮추거나, 힌트를 제공할 수 있도록 단계별 질문 준비

- **시간 조절**: 예상보다 답변이 길어지면 꼬리질문 생략, 짧으면 추가 질문 활용

- **순서 조정**: 긴장을 풀기 위해 쉬운 질문으로 시작, 중간에 어려운 질문, 마지막은 긍정적으로 마무리
