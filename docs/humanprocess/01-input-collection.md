# 01. 입력 자료 수집

> 면접 질문 생성을 위한 기초 자료 준비

---

## 목표

지원자의 기술 역량을 파악할 수 있는 모든 자료를 수집합니다.

---

## 필요한 자료

### 필수 자료

| 자료 | 형식 | 설명 |
|------|------|------|
| **채용공고 (JD)** | 텍스트 | 모집 포지션, 필수/우대 기술 포함 |
| **이력서** | PDF/텍스트 | 경력, 학력, 기술 스택 |

### 선택 자료 (있으면 더 좋음)

| 자료 | 형식 | 설명 |
|------|------|------|
| **포트폴리오** | DOCX/PDF | 프로젝트 상세 설명 |
| **GitHub URL** | 링크 | 실제 코드 확인 가능 |
| **기술 블로그** | 링크 | 기술적 사고방식 파악 |
| **LinkedIn** | 링크 | 추가 경력 정보 |

---

## 자료 수집 체크리스트

```
□ 채용공고 (JD) 텍스트 복사 완료
□ 이력서 내용 확인 (PDF라면 텍스트 복사 가능 여부 확인)
□ GitHub URL 확인 (있는 경우)
  □ 저장소가 Public인지 확인
  □ 주요 저장소 2-3개 선정
□ 포트폴리오 문서 확인 (있는 경우)
□ 지원자 경력 연차 확인 (신입/주니어/미들/시니어)
```

---

## 자료별 준비 방법

### 1. 채용공고 (JD)

채용공고 전문을 텍스트로 복사합니다.

**포함되어야 할 내용:**
- 포지션명
- 담당 업무
- 자격 요건 (필수)
- 우대 사항
- 기술 스택

**예시:**
```
[백엔드 개발자 채용]

담당 업무:
- REST API 설계 및 개발
- 데이터베이스 설계 및 최적화
- 서비스 아키텍처 개선

자격 요건:
- Python 3년 이상 경력
- FastAPI 또는 Django 경험
- PostgreSQL 사용 경험
- Docker 기반 개발 경험

우대 사항:
- Kubernetes 운영 경험
- 대용량 트래픽 처리 경험
- 오픈소스 기여 경험
```

---

### 2. 이력서

이력서에서 다음 정보를 추출합니다.

**추출할 정보:**
- 이름
- 총 경력 연수
- 회사별 경력 (회사명, 기간, 역할, 주요 업무)
- 기술 스택
- 학력
- 자격증/수상 내역

**PDF에서 텍스트 복사가 안 되는 경우:**
1. PDF를 이미지로 캡처
2. AI에게 이미지를 업로드하여 텍스트 추출 요청
3. 또는 수동으로 주요 내용만 타이핑

---

### 3. GitHub URL

지원자의 GitHub 프로필에서 분석할 저장소를 선정합니다.

**저장소 선정 기준 (우선순위):**
1. 지원 포지션과 관련된 기술 스택 사용
2. 최근 1년 내 활동이 있는 저장소
3. 본인이 주요 기여자인 저장소
4. Star/Fork가 많은 저장소
5. README가 잘 작성된 저장소

**수집할 정보:**
```
저장소 1:
- URL: https://github.com/username/repo1
- 주요 기술: Python, FastAPI, PostgreSQL
- 설명: 사용자 관리 API 서버

저장소 2:
- URL: https://github.com/username/repo2
- 주요 기술: React, TypeScript
- 설명: 대시보드 프론트엔드
```

---

### 4. 포트폴리오

포트폴리오 문서에서 프로젝트 정보를 추출합니다.

**추출할 정보 (프로젝트별):**
- 프로젝트명
- 기간
- 역할 (개인/팀, 담당 파트)
- 사용 기술
- 주요 기능
- 성과/결과

---

## 정리 템플릿

수집한 자료를 다음 형식으로 정리합니다:

```markdown
# 지원자 정보 요약

## 기본 정보
- 이름: [이름]
- 경력: [N년차 / 신입]
- 지원 포지션: [포지션명]

## 채용공고 요약
### 필수 기술
- [기술1]
- [기술2]

### 우대 기술
- [기술1]
- [기술2]

### 담당 업무
- [업무1]
- [업무2]

## 지원자 기술 스택
- 언어: [Python, JavaScript, ...]
- 프레임워크: [FastAPI, React, ...]
- 데이터베이스: [PostgreSQL, Redis, ...]
- 기타: [Docker, AWS, ...]

## GitHub 저장소
1. [저장소명1] - [URL]
2. [저장소명2] - [URL]

## 주요 경력
### [회사명1] (YYYY.MM ~ YYYY.MM)
- 역할: [직책]
- 주요 업무: [설명]

### [회사명2] (YYYY.MM ~ YYYY.MM)
- 역할: [직책]
- 주요 업무: [설명]
```

## 팁

- **자료가 부족한 경우**: 이력서와 JD만 있어도 기본적인 질문 생성이 가능합니다. GitHub이나 포트폴리오가 있으면 더 구체적인 질문을 만들 수 있습니다.

- **비공개 저장소**: GitHub 저장소가 Private이라면 지원자에게 주요 코드 스니펫을 요청하거나, 포트폴리오의 코드 설명을 활용합니다.

- **경력 연차 판단**:
  - 신입: 0-1년
  - 주니어: 1-3년
  - 미들: 3-7년
  - 시니어: 7년 이상
