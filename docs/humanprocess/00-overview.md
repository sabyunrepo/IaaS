# Vantict Sniper - 수동 프로세스 가이드

> AI와 함께 맞춤형 기술 면접 질문을 생성하는 수동 워크플로우

---

## 개요

이 가이드는 Vantict Sniper 자동화 시스템 없이, 사람이 AI(Claude, ChatGPT 등)와 협업하여 동일한 품질의 면접 질문을 생성하는 방법을 안내합니다.

### 최종 결과물

- **맞춤형 면접 질문 10개** (지원자 이력/코드 기반)
- **각 질문별 예상 답변 및 평가 기준**
- **면접관용 스크립트** (비개발자도 사용 가능)
- **기술 용어집** (면접관 참고용)

---

## 프로세스 흐름

```
┌─────────────────────────────────────────────────────────────┐
│                    수동 프로세스 흐름                          │
└─────────────────────────────────────────────────────────────┘

[1단계] 입력 자료 수집
    ↓
    • 이력서 (PDF)
    • 포트폴리오 (DOCX)
    • GitHub URL
    • 채용공고 (JD)
    ↓
[2단계] 문서 분석 ──────────────────┐
    ↓                              │
    • 이력서에서 프로필 추출          │ (병렬 진행 가능)
    • 포트폴리오에서 프로젝트 추출     │
    ↓                              │
[3단계] 코드 분석 ──────────────────┤
    ↓                              │
    • GitHub 저장소 탐색             │
    • 주요 코드 패턴 분석             │
    ↓                              │
[4단계] JD 분석 ────────────────────┘
    ↓
    • 필수/우대 기술 추출
    • 기술 용어집 생성
    ↓
[5단계] 질문 생성
    ↓
    • 코드 기반 질문
    • 경험 기반 질문
    • 기술 개념 질문
    ↓
[6단계] 예상 답변 작성
    ↓
    • 핵심 포인트
    • 평가 기준
    • 점수 rubric
    ↓
[7단계] 최종 스크립트
    ↓
    • 면접관용 문서 정리
```

---

## 예상 소요 시간

| 단계 | 소요 시간 | 비고 |
|------|-----------|------|
| 1. 입력 자료 수집 | 5-10분 | 자료가 준비되어 있다면 즉시 |
| 2. 문서 분석 | 10-15분 | AI 프롬프트 2-3회 |
| 3. 코드 분석 | 15-30분 | GitHub 규모에 따라 다름 |
| 4. JD 분석 | 5-10분 | AI 프롬프트 1-2회 |
| 5. 질문 생성 | 15-20분 | AI 프롬프트 3-5회 |
| 6. 예상 답변 작성 | 20-30분 | 질문당 2-3분 |
| 7. 최종 정리 | 10-15분 | 포맷팅 및 검토 |
| **총합** | **약 80-130분** | |

## 필요한 도구

### 필수

| 도구 | 용도 |
|------|------|
| **AI 챗봇** | Claude, ChatGPT 등 (프롬프트 실행) |
| **웹 브라우저** | GitHub 저장소 탐색 |
| **텍스트 에디터** | 결과물 정리 (Notion, Word 등) |

### 선택

| 도구 | 용도 |
|------|------|
| **PDF 리더** | 이력서 내용 복사 |
| **코드 에디터** | 코드 스니펫 정리 (VS Code 등) |
