# Research Skill

## 조사 절차
1. 키워드로 코드베이스 탐색 (Grep, Glob)
2. 관련 파일 읽기 및 분석
3. 외부 정보 필요 시 `brave-search` MCP 활용
4. 라이브러리 문서 필요 시 `context7` MCP 활용
5. 파일 참조(`file:line`)와 함께 결과 정리

## 원칙
- 읽기 전용 도구만 사용 (코드 수정 금지)
- 결과에 항상 파일 경로와 라인 번호 포함
- 불확실한 부분은 명시
